# 实现右侧商品栏滚动定位交互功能

## 需求概述

当用户向下滚动页面至"本店推荐"区域底部时，右侧商品栏取消固定定位，随页面正常流动；向上滚动至"本店推荐"区域重新进入视口时，恢复固定定位。

## 当前状态分析

当前右侧商品栏的定位逻辑位于 `ProductDetailPage.vue`，核心实现方式为：

- **CSS**：`.right-sticky` 使用 `position: fixed; top: 24px;`，通过 `stickyStyle` 响应式对象动态设置 `width`、`right`、`top`
- **JS**：`updateStickyPosition()` 函数在 `scroll` 事件中触发，计算元素 `getBoundingClientRect()` 来同步宽度和右侧偏移，并控制 `isStuck` 状态（`scrollTop >= 36` 时置为 `true`）
- **问题**：当前固定定位没有底部边界，右侧商品栏会一直固定在视口中，即使页面已滚动到"本店推荐"区域之后

## 方案选择

### 方案：CSS `position: sticky` 替换手动 JS 固定定位

**理由**：`position: sticky` 天然支持"在滚动容器内固定，到达父容器底部边界时释放"的行为，无需手动计算。`position: sticky` 的释放时机正是元素的底部到达其父容器底部时，而父容器 `.product-detail__right` 作为 flex 项拉伸到与左侧列等高（左侧列底部即为"本店推荐"区域底部），因此 sticky 的释放时机与需求完全吻合。

### 为什么不用手动 JS 方案

- 需要额外维护 placeholder 元素来保持布局高度
- 从 `fixed` 切换到 `static` 时元素会跳转到视口外，需要复杂的 `absolute` + `top` 计算
- 代码量更大，维护成本更高

## 具体改动

### 1. CSS 修改 — `.right-sticky`

| 属性 | 修改前 | 修改后 |
|------|--------|--------|
| `position` | `fixed` | `sticky` |
| `top` | `24px` | 不变 |
| `width` | 由 `stickyStyle` 动态设置（JS 内联） | 删除（sticky 元素保持流内布局，宽度自动继承父容器） |

### 2. Template 修改

**`<div class="right-sticky" :style="stickyStyle">`**
→ 移除 `:style="stickyStyle"`，改为 `<div class="right-sticky">`

### 3. JS 修改

**删除以下变量/对象：**
- `stickyStyle` 响应式对象（第 392 行）
- `resizeObserver` 变量（第 394 行）

**简化 `updateStickyPosition()` 函数：**
- 移除 `rect` 计算（`width`、`right`）
- 移除 `stickyStyle.top` 的动态计算
- 仅保留 `isStuck` 更新逻辑（`scrollTop >= 36`），用于控制 `promo-tip` 的显隐

**更新 `onMounted`：**
- 移除 `window.addEventListener('resize', updateStickyPosition)` — 不再需要
- 移除 `ResizeObserver` 创建和绑定 — 不再需要
- 保留 `scroll` 监听器（仅用于 `isStuck` 更新）
- 保留 `updateStickyPosition()` 初始调用

**更新 `onUnmounted`：**
- 移除 `window.removeEventListener('resize', updateStickyPosition)`
- 移除 `resizeObserver.disconnect()`
- 保留其他清理逻辑

### 4. `promo-tip` 过渡效果

`promo-tip` 已有的 CSS 过渡（`max-height`、`opacity`、`margin-bottom`、`padding` 的 `0.3s ease` 动画）保持不变，`v-show="!isStuck"` 控制逻辑不变。

## 预期行为

1. **页面顶部**：右侧商品栏在正常流中，位于 `.product-detail__right` 顶部
2. **向下滚动**：当右侧商品栏顶部到达 `top: 24px` 位置时，`position: sticky` 激活，固定在视口顶部附近
3. **继续向下滚动至"本店推荐"区域**：右侧商品栏保持固定，直到其底部到达 `.product-detail__right` 底部（即"本店推荐"区域底部），此时 sticky 自动释放，商品栏随页面正常流动
4. **向上滚动**：当"本店推荐"区域重新进入视口，`position: sticky` 重新激活，右侧商品栏恢复固定

## 不涉及的文件

本改动仅涉及 `src/views/product/ProductDetailPage.vue` 一个文件，不影响其他组件、路由、store 或 mock 数据。

## 验证方式

1. 打开商品详情页，向下滚动，确认右侧商品栏在 `top: 24px` 处固定
2. 继续滚动至"本店推荐"区域，确认右侧商品栏释放固定，随页面流动
3. 向上滚动至"本店推荐"区域重新进入视口，确认右侧商品栏恢复固定
4. 确认 `promo-tip` 在滚动超过 TopUtilityBar（36px）时隐藏，并有过渡动画
